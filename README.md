## 📌 Sobre o Projeto

Este repositório reúne as atividades desenvolvidas no curso **Mineração de Dados (ACH5504-2021203)**, com foco na aplicação de técnicas de **mineração de dados** em diferentes contextos. O projeto aborda conceitos de **agrupamento**, **classificação**, **análise de componentes principais (PCA)** e **regras de associação**.

As atividades do curso incluem análise de dados, implementações de algoritmos, testes de diferentes métodos de aprendizado e extração de padrões significativos.

## 📌 Atividades e Tarefas

### 1. **Tarefa 1 - Similaridade de Enzimas entre Organismos**
   - **Objetivo**: Analisar a similaridade de enzimas entre diferentes organismos utilizando técnicas de distância e agrupamento.
   - **Data de Entrega**: 27 de setembro de 2021  
🔗 [Ver Pasta](tarefas/tarefa1_similaridade_enzimatica)

### 2. **Tarefa 2 - Análise de Componentes Principais (PCA)**
   - **Objetivo**: Realizar a redução de dimensionalidade em dados utilizando PCA, visualizando a explicação de variância de cada componente.
   - **Data de Entrega**: 11 de outubro de 2021  
🔗 [Ver Pasta](tarefas/tarefa2_pca)

### 3. **Tarefa 3 - Classificação de Sementes de Trigo**
   - **Objetivo**: Aplicar algoritmos de **classificação** (KNN, Árvores de Decisão) para classificar sementes de trigo com base em atributos como área e perímetro.
   - **Data de Entrega**: 1 de novembro de 2021  
🔗 [Ver Pasta](tarefas/tarefa3_classificacao_sementes)

### 4. **Tarefa 4 - Testando Métodos de Agrupamento**
   - **Objetivo**: Testar e comparar diferentes algoritmos de **agrupamento**, como KMeans, para classificar dados em grupos.
   - **Data de Entrega**: 13 de dezembro de 2021  
🔗 [Ver Pasta](tarefas/tarefa4_agrupamento)

### 5. **Tarefa 5 - Regras de Associação: Plantas Mais Frequentes nos EUA e Canadá**
   - **Objetivo**: Encontrar conjuntos de plantas que ocorrem frequentemente nos EUA e no Canadá utilizando técnicas de regras de associação.
   - **Data de Entrega**: 20 de dezembro de 2021  
🔗 [Ver Pasta](tarefas/tarefa5_regras_associacao)

## ▶️ Como Executar

### 1. Clone o repositório

```bash
git clone https://github.com/GiulianaPola/mineracao-dados-usp.git
```

### 2. Instale as dependências

```bash
pip install -r requirements.txt
# ou manualmente:
pip install pandas numpy scikit-learn matplotlib seaborn
```

### 3. Execute os notebooks

```bash
jupyter notebook
```
